# Dungeon Escape

**Dungeon Escape** — это 2D-игра в жанре приключения, разработанная на языке Python с использованием библиотеки Pygame.

Игрок исследует подземелье, перемещается по карте, избегает стен и должен добраться до выхода.

## Возможности игры

- Двумерная карта подземелья.
- Управление персонажем с помощью WASD или стрелок.
- Столкновения со стенами.
- Главное меню игры.
- Отображение здоровья и очков игрока.
- Экран победы.
- Экран окончания игры.
- Возможность перезапуска игры.

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/UUST-MCS-2026/dungeon-escape.git
```

2. Перейдите в папку проекта:

```bash
cd dungeon-escape
```

3. Создайте виртуальное окружение:

```bash
python3 -m venv .venv
```

4. Активируйте его:

```bash
source .venv/bin/activate
```

5. Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

6. Запустите игру:

```bash
python3 main.py
```

## Управление

| Клавиша | Действие |
|---|---|
| W / ↑ | Движение вверх |
| S / ↓ | Движение вниз |
| A / ← | Движение влево |
| D / → | Движение вправо |
| ENTER | Начать игру |
| ESC | Выйти из игры |
| R | Перезапустить игру |

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Основной игровой цикл и логика игры |
| `player.py` | Управление персонажем и столкновения |
| `level.py` | Карта подземелья, стены и выход |
| `ui.py` | Главное меню и игровой интерфейс |
| `settings.py` | Настройки игры |
| `requirements.txt` | Список зависимостей |

## Организация совместной работы

Для совместной разработки используется GitHub.

- Каждый участник работает в собственной ветке.
- Изменения сохраняются с помощью Commit.
- Для объединения изменений создаются Pull Request.
- После проверки изменения объединяются с основной веткой `main`.
